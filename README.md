# 💕 Heart of Fantasy - RPG Textuel Narratif

Un jeu RPG textuel élaboré avec système d'affinité romantique profond, aventure immersive et 20+ personnages romantiques secondaires.

## 🎮 Caractéristiques

- **Système Narratif Branché** : 300+ dialogues uniques
- **Système d'Affinité Avancé** : relations évolutives avec chaque personnage
- **1 Héroïne Principale** + **20 Personnages Romantiques Secondaires**
- **Aventure Complète** : Quêtes, combats, exploration
- **Multiples Fins** selon vos choix amoureux
- **Sauvegarde/Progression** complète
- **Interface Web Interactive**

## 🚀 Installation

```bash
# Cloner le repository
git clone https://github.com/dddddddddddddddddddddddA/heart-of-fantasy.git
cd heart-of-fantasy

# Installer les dépendances
pip install -r requirements.txt

# Lancer le serveur
python server.py
```

Puis ouvrez : `http://localhost:5000`

1. Créez votre personnage

## 🎯 Système de Jeu

### Affinité (0-100)
- **0-25** : Connaissance basique
- **26-50** : Amitié croissante
- **51-75** : Connexion profonde
- **76-100** : Amour véritable

### Dialogues Déblocables
Chaque niveau d'affinité déverrouille des dialogues uniques et profonds.

### Choix Impactants
Chaque décision affecte l'affinité et l'histoire globale.

### Quêtes Personnelles
Chaque personnage a des quêtes uniques qui approfondissent la relation.

## 🎮 Commandes de Jeu

- `parler` : Engager une conversation
- `explorer` : Découvrir de nouveaux lieux
- `quêtes` : Voir les quêtes disponibles
- `stats` : Voir vos relations
- `sauvegarder` : Sauvegarder votre progression
- `charger` : Charger une sauvegarde

## 📊 Fins Possibles

- **Fin Solitaire** : Triompher seul(e)
- **15+ Fins Romantiques** : Une pour chaque personnage
- **Fin Poly** : Unions multiples
- **Fins Tragiques** : Si vous perdez vos relations
- **Fin Secrète** : Débloquez-la avec tous les personnages
