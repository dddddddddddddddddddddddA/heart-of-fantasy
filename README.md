# Heart of Fantasy - RPG Textuel Romantique

Un jeu RPG textuel immersif en Fantasy avec un système de relations amoureuses élaboré.

## 🎮 Caractéristiques

- **1 Héros Principal Masculin** : Vous, un aventurier avec un passé énigmatique
- **18 Héroïnes Secondaires Féminines** : Chacune avec une quête unique et une histoire d'amour développée
- **Système d'Affinité Avancé** : Points de relation, dialogues déblocables, fins multiples
- **200+ Dialogues** : Narratif branché et conséquences réelles
- **Quêtes Dynamiques** : Lieux à explorer, énigmes, combats tactiques
- **Sauvegarde Complète** : Progression sauvegardée et gérée
- **Interface Immersive** : Terminal-like avec JavaScript/Python

## 🛠️ Stack Technologique

- **Backend** : Python (Flask)
- **Frontend** : JavaScript Vanilla + HTML/CSS
- **Architecture** : MVC

## 🚀 Installation

```bash
pip install -r requirements.txt
python server.py
```

Ouvrez `http://localhost:5000` dans votre navigateur.

## 💕 Système de Relations

Chaque héroïne a :
- Points d'affinité (0-100)
- Dialogues déblocables
- Quête personnelle
- Fins romantiques uniques
- Événements spéciaux

## 📖 Narratif

Explorez un monde fantasy riche avec 5 royaumes, 20+ lieux, et découvrez l'amour au-delà des frontières.
